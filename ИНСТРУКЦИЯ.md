Скидываю скриншоты работы, на первом скриншоте можете видеть канал откуда пересылаются смс, во втором куда они пересылаются, а на третьем часть интерфейса бота где четко видно что был добавлен фильтр на цифру 10 и не было переслано смс как раз с смс номер 10.

# Инструкция по установке и использованию

## Что делает программа

Бот автоматически пересылает сообщения из одного канала телеграма в другой. Поддерживает фото, видео, кружки, голосовые, документы, форматирование текста. Можно настроить фильтры по словам и задержку между публикациями.

---

## Часть 1. Установка

### Windows

**Шаг 1. Установите Python**

Перейдите на сайт python.org, раздел Downloads, скачайте последнюю версию Python 3 для Windows.

При установке обязательно поставьте галочку "Add Python to PATH" - она находится внизу первого окна установщика.

Проверьте установку - откройте командную строку (Win+R, введите `cmd`, нажмите Enter) и выполните:

```
python --version
```

Должна появиться версия, например `Python 3.12.0`.

**Шаг 2. Распакуйте архив**

Распакуйте прикреплённый архив в любую удобную папку, например `C:\forwarder`.

**Шаг 3. Откройте папку в командной строке**

Зайдите в папку с программой через проводник, нажмите на адресную строку вверху, введите `cmd` и нажмите Enter. Откроется командная строка уже в нужной папке.

**Шаг 4. Установите зависимости**

```
pip install -r requirements.txt
```

Дождитесь окончания установки.

**Шаг 5. Создайте файл настроек**

В папке с программой создайте файл `.env` (именно с точкой в начале). Откройте блокнот, вставьте:

```
BOT_TOKEN=сюда_токен_бота
ADMIN_IDS=сюда_ваш_id
```

Сохраните как `.env` - при сохранении в поле "Тип файла" выберите "Все файлы", иначе создастся `.env.txt`.

## Часть 2. Получение данных для настройки

### Токен бота (BOT_TOKEN)

1. Откройте телеграм и найдите [@BotFather](https://t.me/BotFather)
2. Напишите `/newbot`
3. Придумайте и введите название бота (например `Мой форвардер`)
4. Придумайте и введите имя пользователя бота - оно должно заканчиваться на `bot` (например `myforwarder_bot`)
5. Скопируйте токен - выглядит примерно так: `7123456789:AAHxxx...`
6. Вставьте в `.env` как значение `BOT_TOKEN`

### Ваш ID в телеграме (ADMIN_IDS)

1. Найдите в телеграме [@userinfobot](https://t.me/userinfobot)
2. Напишите ему любое сообщение
3. Он ответит вашим ID - скопируйте число
4. Вставьте в `.env` как значение `ADMIN_IDS`

### API ID и API Hash (понадобятся позже, при добавлении аккаунта)

1. Откройте сайт my.telegram.org в браузере
2. Войдите с номером телефона вашего телеграм-аккаунта
3. Нажмите "API development tools"
4. Заполните форму: App title - любое название, Short name - любое слово на латинице
5. Нажмите "Create application"
6. Скопируйте `App api_id` и `App api_hash` - они понадобятся на следующем шаге

## Часть 4. Использование бота

### Добавление аккаунта телеграма

Для пересылки нужен аккаунт телеграма (не бот), который подписан на канал-источник. В целевом канале этот аккаунт должен быть администратором с правом публикации.

1. Нажмите `➕ Додати акаунт`
2. Введите любое имя для аккаунта, например `main`
3. Введите API ID (число, полученное на my.telegram.org)
4. Введите API Hash (строка, полученная на my.telegram.org)
5. Введите номер телефона с кодом страны, например `+79991234567`
6. Вам придёт код подтверждения в телеграм - введите его через пробелы: `1 2 3 4 5`
7. Если на аккаунте включена двухфакторная защита - введите пароль

### Добавление каналов

**Канал-источник** - канал откуда берутся сообщения:

1. Нажмите `📺 Додати джерело`
2. Введите username канала через @ (например `@newsChannel`) или его числовой ID (например `-1001234567890`)

**Канал-получатель** - канал куда пересылаются сообщения:

1. Нажмите `📤 Додати отримувач`
2. Введите username или ID целевого канала

Как узнать ID канала: перешлите любое сообщение из канала боту [@userinfobot](https://t.me/userinfobot) - он покажет ID.

### Связывание каналов

После добавления источника и получателя их нужно связать:

1. Нажмите `🔗 Зв'язати канали`
2. Введите номер источника из списка
3. Введите номер получателя из списка

Можно создать несколько связей: один источник - несколько получателей, или несколько источников - один получатель.

### Настройки фильтров и интервала

Нажмите `⚙️ Налаштування`:

**Фильтры (стоп-слова)**

Если добавить стоп-слово, сообщения содержащие это слово пересылаться не будут.

- `🔎 Додати фільтр` - введите слово или фразу, например `реклама`
- `🗑 Видалити фільтр` - выберите номер фильтра для удаления

Регистр не важен: фильтр `реклама` заблокирует и `Реклама` и `РЕКЛАМА`.

**Интервал между публикациями**

- `⏱ Встановити інтервал` - введите количество секунд между пересылками
- `0` - пересылать мгновенно
- `60` - делать паузу 60 секунд между каждым сообщением

### Запуск и остановка пересылки

- `▶️ Запустити` - начать пересылку
- `⏸ Зупинити` - остановить пересылку

После нажатия "Запустити" бот начнёт отслеживать новые сообщения в каналах-источниках и пересылать их в целевые каналы.

## Часть 5. Постоянная работа на сервере (Linux)

Чтобы программа работала круглосуточно без необходимости держать компьютер включённым, нужен VPS-сервер.

### Настройка автозапуска через systemd

Создайте файл службы:

```bash
sudo nano /etc/systemd/system/tgforwarder.service
```

Вставьте (замените путь на реальный путь к папке программы):

```ini
[Unit]
Description=Telegram Channel Forwarder
After=network.target

[Service]
WorkingDirectory=/root/telethon-channel-forwarder
ExecStart=/usr/bin/python3 main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Сохраните: Ctrl+O, Enter, Ctrl+X.

Активируйте и запустите:

```bash
sudo systemctl enable tgforwarder
sudo systemctl start tgforwarder
```

Проверить статус:

```bash
sudo systemctl status tgforwarder
```

Посмотреть логи:

```bash
sudo journalctl -u tgforwarder -f
```

### Быстрый вариант через screen

Если не хотите настраивать systemd:

```bash
screen -S forwarder
python3 main.py
```

Для выхода без остановки нажмите Ctrl+A, затем D.

Для возврата к сессии:

```bash
screen -r forwarder
```

## Часть 6. Решение проблем

**Бот не отвечает**
- Проверьте что программа запущена
- Убедитесь что токен в `.env` правильный
- Проверьте интернет-соединение

**Ошибка при добавлении аккаунта**
- Проверьте правильность API ID и API Hash
- Убедитесь что номер телефона введён с кодом страны (например `+7` для России)
- Убедитесь что телефон может получить смс или звонок от телеграма

**Пересылка не работает после запуска**
- Убедитесь что аккаунт является подписчиком канала-источника
- Убедитесь что аккаунт является администратором целевого канала с правом публикации
- Проверьте что связь между каналами создана через `🔗 Зв'язати канали`

**Сессия устарела**
- Удалите аккаунт через `🗑 Видалити акаунт`
- Добавьте его заново через `➕ Додати акаунт`

**Файл `.env` не создаётся (Windows)**
- При сохранении в блокноте выберите "Все файлы" в поле "Тип файла"
- Убедитесь что имя файла именно `.env`, без дополнительных расширений
